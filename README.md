# 🎭 Theater API

An API for managing theater plays, halls, reservations, and tickets. Built with Django.

---

## 🚀 How to Run the Project Locally

### Requirements

- Python 3.9+
- Docker and Docker Compose (recommended for easy setup)
- Git

### Clone the Repository
    git clone https://github.com/AlexTarasov57/API_service_for_theate.git

## API Features

- **Actors Management:**  
  Create, update, list, and view actors involved in plays.

- **Genres Management:**  
  Add and manage unique genres for categorizing plays.

- **Plays Catalog:**  
  Manage theater plays with detailed descriptions, associated actors, and genres.

- **Theater Halls:**  
  Define theater halls with configurable rows and seats, automatically calculating total capacity.

- **Performances Scheduling:**  
  Schedule specific performances of plays in selected halls at designated times.

- **Reservations System:**  
  Allow users to create reservations linked to their accounts.

- **Ticket Booking:**  
  Book tickets for performances with seat and row validation to prevent double booking and invalid seat selection.

- **Data Validation:**  
  Robust validation on seat numbers and ticket uniqueness to ensure data integrity.

- **Ordering and Sorting:**  
  Default ordering for plays by title and performances by show time.
